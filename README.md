# 🌳 PATROUILLE-PARCS

Application de gestion des tournées de fermeture des parcs pour les CCFF.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Leaflet
- PWA (à venir)

## Fonctionnalités

- 🗺️ Carte interactive
- 📍 GPS en temps réel
- 🚓 Mode Patrouille
- 📱 Mode Terrain
- ✅ Fermeture des parcs
- 📜 Historique
- 🔄 Réinitialisation de tournée
- ℹ️ À propos

## Structure

```
src/
 ├── components/
 ├── hooks/
 ├── screens/
 ├── utils/
 ├── data/
 └── App.tsx
```

## Lancement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
